---
name: Identity profile roadmap
description: Durable scope boundary for the Yodocto professional identity MVP.
---

The current Yodocto MVP prioritizes a usable public identity, editable profile sections, wallet-ready QR/barcode sharing, and resume extraction with candidate review before saving.

**Why:** Authentication and protected file storage were not configured in the workspace when the profile expansion was implemented, so those capabilities should be integrated as explicit follow-up work rather than represented as fully live services.

**How to apply:** Keep extracted profile fields editable and only publish the reviewed saved state. Tie future uploads to protected object storage and future profile ownership to managed authentication.
